# Spire Muses — La Torre de las Musas

Deckbuilder roguelike en el navegador. Funciona en PC, tablet y móvil (en horizontal). Sin instalación.

Jugar: activa **GitHub Pages** (Settings → Pages → Deploy from branch → `main` / `/ (root)`) y abre la URL que te da.
En local: `python3 -m http.server` en esta carpeta y abre http://localhost:8000.

Controles: toca/clic en una carta para elegirla y otra vez para jugarla; toca al enemigo si hace falta. Partida guardada en el navegador.
